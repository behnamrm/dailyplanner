# Daily Planner

A project and task tracker with Pomodoro-based focus mode.

## Features

- **Create Task**: define a task with a title, deadline, category, and subtasks/to-dos, then save it as a draft or publish it.
- **Focus**: pick a published task's subtask and run it through a Pomodoro timer (focus / short break / long break).
- **My Tasks**: browse all tasks with search, category and status filters, sorting, and inline progress tracking.
- **Settings**: manage categories, Pomodoro durations, and export/import a full JSON backup of your data.

All data is stored locally in the browser (`localStorage`) — no account or backend required.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
